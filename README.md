# BibliotecaFP

Proyecto didáctico para gestionar libros, usuarios y préstamos de una biblioteca de FP.

## Estado
Prototipo inicial. No requiere instalar dependencias externas.

## Estructura
- `src/`: código de ejemplo.
- `data/`: datos ficticios en CSV.
- `docs/`: requisitos y funcionalidades previstas.
- `tests/`: pruebas iniciales.

## Ejecución
Desde la raíz del proyecto: `python src/main.py`
